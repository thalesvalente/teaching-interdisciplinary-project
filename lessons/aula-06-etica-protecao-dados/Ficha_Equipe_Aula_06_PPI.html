    Precisa relembrar? Cinco perguntas antes de usar um dado

    1 · Necessidade

    Precisamos disso?

    Use apenas o mínimo necessário para uma finalidade clara.

    2 · Identificação

    Identifica alguém?

    Diretamente ou pela combinação de informações.

    3 · Sensibilidade

    É dado sensível?

    Saúde, origem racial ou étnica e biometria vinculadas a uma pessoa são exemplos legais.

    4 · Autorização

    Podemos usar?

    Confirmem o procedimento institucional. Consentimento não é a única base legal.

    5 · Proveniência

    De onde veio?

    Registrem fonte, data/versão, transformações, responsáveis e restrições.

    Uma fonte pública não autoriza qualquer uso de dados pessoais. Dados sintéticos não devem representar pessoas reais; dados agregados e pseudonimizados ainda exigem cuidado com a identificação.
